# Pool Trajectory Offline

Android/Kotlin-проект локального помощника для тренировочного/оффлайн режима пула.

## Возможности

- захват экрана через Android MediaProjection;
- foreground-service типа `mediaProjection`;
- прозрачный non-touchable overlay поверх игры;
- локальное распознавание шаров OpenCV;
- автоматический поиск белого шара;
- оценка направления кия;
- расчёт первого столкновения шаров;
- ghost-ball;
- линия прицельного шара;
- касательная траектория битка после контакта;
- 0–2 идеальных рикошета от бортов;
- режим калибровки;
- настройка чувствительности и FPS анализа.

Приложение не запрашивает INTERNET permission: обработка выполняется локально.

## Облачная сборка APK

После каждого push GitHub Actions запускает сборку debug APK. Открой вкладку **Actions** → последний запуск **Build Android APK** → внизу страницы скачай artifact **PoolTrajectoryOffline-debug-apk**.

## Запуск

1. Установи APK.
2. Запусти Pool Trajectory Offline.
3. Разреши показ поверх приложений.
4. Нажми «Запустить анализ экрана».
5. Подтверди системный захват экрана. На Android 14+ выбери захват только приложения 8 Ball Pool.
6. Открой оффлайн-матч с ботом.

Проект предназначен для тренировочного/оффлайн использования.
