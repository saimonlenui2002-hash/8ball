# Durak Lens — Android 16 calibration build

Локальный экранный помощник для офлайн-партии в переводного дурака. Профиль
создан по записи 720×1574 для классической колоды из 24 карт.

## Что реализовано

- захват окна выбранной игры через `MediaProjection`;
- foreground service, совместимый с требованиями Android 14–16;
- перетаскиваемое окно поверх игры;
- распознавание достоинства и масти по шаблонам из записи;
- распознавание остатка колоды: 12, 10, 8, 6, 4, 2 или 0;
- учёт карт руки, стола, отбоя и карт, которые мог забрать соперник;
- разделение карт соперника на известные и возможные;
- подсказки атаки, защиты, перевода, взятия и завершения раунда.

## Сборка

1. Открыть корневую папку `DurakAssistant` в актуальной Android Studio.
2. Выбрать JDK 17 и установить Android SDK 36.
3. Если IDE попросит создать Gradle Wrapper, выбрать Gradle 8.11.1.
4. Выполнить `Build > Build APK(s)`.

Проект использует AGP 8.10.1 и Kotlin 2.1.20. Интернет нужен только Android
Studio при первой загрузке инструментов и зависимостей; само приложение работает
локально.

### Сборка через GitHub без компьютера

После загрузки проекта в отдельный репозиторий GitHub автоматически запускает
`.github/workflows/build-apk.yml`. На странице `Actions` нужно открыть последний
зелёный запуск и скачать артефакт `DurakLens-debug-apk`. Внутри ZIP находится
готовый `app-debug.apk`. Сборку также можно повторить кнопкой `Run workflow`.

## Использование

1. Запустить Durak Lens и разрешить уведомления и окно поверх других приложений.
2. Нажать «Начать анализ».
3. В системном окне выбрать **одно приложение**, затем офлайн-игру.
4. Начать новую партию 24 карты / переводной режим.
5. Перетащить панель так, чтобы она не закрывала руку и стол. Касание панели
   сворачивает или разворачивает подробности.

## Важные ограничения первой версии

- профиль откалиброван по одной партии и одному разрешению;
- точными считаются только реально замеченные карты; рубашки не содержат
  сведений о достоинстве и масти;
- после изменения масштаба интерфейса, темы, рисунка карт или системного размера
  экрана потребуется повторная калибровка;
- при уверенности распознавания ниже 72% трекер сохраняет последнее стабильное
  состояние, чтобы один плохой кадр не испортил партию;
- советник использует безопасную эвристику, а не полный перебор всех будущих
  раздач.

## Структура

- `capture/CaptureService.kt` — захват кадров и жизненный цикл Android 16;
- `vision/` — профиль координат, шаблоны и классификация;
- `game/` — колода, трекер состояния и советник;
- `overlay/OverlayController.kt` — плавающее окно.
